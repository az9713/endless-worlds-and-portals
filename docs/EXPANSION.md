# Portals: Beyond — local derivative

The original engine and initial 471 worlds were designed and built by AI agents working with Ethan Mollick. Original repository: https://github.com/emollick/ai-portals, upstream commit 210133f4e718acb7b461f2a40c90661a40a2397f.

This local derivative adds new worlds identified by `x-` prefixes, new journeys, an original-world gallery filter, local sharing and keyboard-accessibility repairs. New worlds are authored by Codex and collaborating agents in response to the user's request. They are not attributed to Ethan Mollick.

The derivative is licensed CC BY-NC-SA 4.0, preserving upstream attribution and the noncommercial/share-alike terms. See LICENSE and THIRD-PARTY-NOTICES.txt. Three.js is separately licensed MIT.

Science environments are artistic interpretations; individual descriptions identify where numerical models or particular mathematical constructions are used. They are not validated physical simulations.

This package defaults sharing metadata to a local preview address. Set PORTALS_SITE to the actual origin before any future deployment. No public deployment is part of this local build.
